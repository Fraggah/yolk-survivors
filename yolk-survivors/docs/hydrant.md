# Hydrant: continuous mayonnaise stream

All four tiers use a continuous hitscan stream instead of projectile scenes. Normal weapon range controls target acquisition and maximum stream length. The stream follows the current nearest target and stops when there is no target in range. A curved Line2D with an animated mayonnaise shader connects the muzzle to the last hit: pale center, slightly darker edges, moving thickness variations and subtle lateral wobble. Endpoints stay attached to muzzle/impact. Visual wobble is bounded relative to the actual hit width.

A shared world-space particle pool emits small cream droplets at the muzzle and denser sprays at every enemy touched by the stream. They continue falling briefly after emission stops, pause with gameplay and clear at wave transitions. A hard 1800-particle cap bounds all streams together. Particle emission uses a separate visual interval rather than changing damage ticks. The pool preallocates/reuses particle records and fixed MultiMesh storage. Expiry uses swap-remove, avoiding array shifts. One MultiMeshInstance2D draws every droplet's three layers (edge/body/highlight) using per-instance transforms/colors and an antialiased circular shader. Visible instance count hides unused slots; clearing returns records exactly once. Tests in verify_mayonnaise_pool cover capacity, expiry, pause, clear and reuse.

Damage is applied once on activation and at each effective cooldown interval while active. Attack speed changes this tick interval. Each tick uses normal ranged damage scaling, per-target critical rolls, lifesteal, knockback, on-hit statuses and weapon damage accounting. The first enemy blocks the stream by default; piercing allows additional distinct enemies behind it. The thick-line query uses actual enemy hurtboxes. No bouncing is performed. At most four ticks are processed in one frame to avoid lag catch-up bursts.

Pause freezes tick timing and the visual. Arena cleanup resets the stream immediately; preparing the next wave resets it again. Selling removes the stream with its owning weapon. Each copy has an independent stream/tick timer. The existing weapon sound plays at stream activation rather than on every damage tick; looping sound can be polished later.

Edit `resources/items/weapons/range/hydrant/stats_hydrant_<tier>.tres`: `damage` is damage per tick, `cooldown` is the base tick interval, `max_range` controls detection and stream length. Usual crit/knockback/scaling stats remain available. Expand `ranged_settings` → Continuous stream for width, body/core/edge colors, wobble, flow speed, particle interval, muzzle/impact counts, lifetime and particle speed. Legacy projectile_speed/recoil values are not used by the continuous implementation.

Scripts: `scenes/weapons/range/hydrant_weapon.gd` controls aim plus continuous updates; `mayonnaise_stream.gd` performs queries, ticks and curved geometry; `shaders/mayonnaise_stream.gdshader` shades the strand; `effects/mayonnaise_particles.gd` handles pooled splashes. Regression `tests/verify_hydrant_stream.gd` validates all tiers, first-target blocking, piercing, damage accounting, no projectile nodes, curved/shaded geometry, both emission types, paused particles, reacquisition and wave cleanup.
